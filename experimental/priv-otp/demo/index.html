Le principe

Deux appareils qui partagent le même secret et la même heure peuvent calculer le même code. Ici, la clé est volontairement publique : tout le monde obtient le même résultat.

Pour un vrai usage, le secret devrait être créé et protégé sur les appareils concernés. Il faudrait aussi un autre appareil pour lire le code pendant que l’iPhone est verrouillé.

Voir la clé publique utilisée

Vecteur de test SHA-256 du RFC 6238, encodé en UTF-8 (32 octets) :

12345678901234567890123456789012

Le profil de cet aperçu utilise une période de 60 secondes et 6 chiffres. Ce fichier ne crée, n’importe et ne conserve aucun secret personnel.

Fonctionne hors ligne dans un navigateur compatible avec Web Crypto. Aucune donnée enregistrée, aucun appel réseau.
